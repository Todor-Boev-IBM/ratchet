<h1 align="center">Ratchet</h1>

Ratched is a agentic coding development method that puts the developer mental load and code quality at the center.

Ratchet takes a principled stance against the Spec Driven Development family of workflows. While Ratchet is also
driven by markdown plans and proposals they serve only to move the codebase forward and become historical record
once their job is done.

Ratched consists of rules, custom modes, MCP server settings and skills.
All of these are bound together by a human workflow that is the heart of the process.

- [Setup](setup.md) — merge configuration into your `.bob` directory
- [Process](docs/architecture/README.md) — the coding workflow: graphical prompting and parallelism
